# Aseprite Scripts

[English](README.md) | 日本語

[Aseprite](https://www.aseprite.org/) 用のスクリプト集です(拡張機能も1つあります)。日本語版のスクリプトは [`ja`](ja) フォルダに入っています。

| スクリプト | できること |
| --- | --- |
| [プリセットから新規作成](#プリセットから新規作成) | 登録しておいたキャンバスサイズを選んで新規スプライトを作ります。 |
| [GIFをレイヤーとして読み込み](#gifをレイヤーとして読み込み) | GIF アニメーションを、開いているスプライトにレイヤーとして読み込みます。 |
| [全レイヤーの色を置き換え](#全レイヤーの色を置き換え) | 全レイヤー・全フレームの指定した色を、まとめて別の色に置き換えます。 |
| [効果レイヤーを作成](#効果レイヤーを作成) | 選択中のレイヤーと同じ形の色レイヤーを、乗算などのレイヤーモードで上に作ります。 |
| [ベジェ曲線](#ベジェ曲線)(拡張機能) | 「曲線レイヤー」を追加します。ベジェ曲線で引いた線を、いつでもキャンバス上で編集できます。 |

## インストール

1. 使いたい `.lua` ファイルをダウンロードします。
   - [`プリセットから新規作成.lua`](ja/プリセットから新規作成.lua)
   - [`GIFをレイヤーとして読み込み.lua`](ja/GIFをレイヤーとして読み込み.lua)
   - [`全レイヤーの色を置き換え.lua`](ja/全レイヤーの色を置き換え.lua)
   - [`効果レイヤーを作成.lua`](ja/効果レイヤーを作成.lua)

   まとめて入手するときは、このページの **Code > Download ZIP** を使い、中の `ja` フォルダから取り出してください。
2. Aseprite で **ファイル > スクリプト > スクリプトフォルダを開く**(File > Scripts > Open Scripts Folder)を選びます。
3. 開いたフォルダに `.lua` ファイルをコピーします。
4. **ファイル > スクリプト > スクリプトフォルダを再スキャン**(File > Scripts > Rescan Scripts Folder)を選びます(Aseprite を再起動してもかまいません)。

これで **ファイル > スクリプト** の中にスクリプトが並びます。**編集 > キーボードショートカット** でショートカットキーを割り当てることもできます。

同じスクリプトの英語版はリポジトリの一番上の階層にあります。中身は同じなので、入れるのはどちらか一方で大丈夫です。

ベジェ曲線は拡張機能なので、入れ方が違います。

1. [`bezier-curve.aseprite-extension`](extensions/bezier-curve.aseprite-extension) をダウンロードします。
2. ダブルクリックします(Windows・macOS)。または Aseprite で **編集 > 環境設定 > 拡張機能 > 拡張機能を追加** を選び、そのファイルを選びます。

一度入れれば、Aseprite を起動するたびに使えます。メニューやメッセージは、Aseprite の表示言語に合わせて日本語か英語になります。外すときは、同じ拡張機能の画面で **アンインストール** を選びます。

## プリセットから新規作成

登録しておいたキャンバスサイズを選んで新規スプライトを作ります。毎回幅と高さを入力する手間が省けます。

- 登録済みのサイズを選ぶだけで新規スプライトを作成
- プリセットの追加・上書き・削除をダイアログから操作
- カラーモードを選択(RGB / グレースケール / インデックス)
- 背景を選択(透明 / 白 / 今の背景色)
- プリセットはテキストファイルに保存されるので、手で書き換えることもできる

### 使い方

**ファイル > スクリプト > プリセットから新規作成** を実行します。

| 項目 | 説明 |
| --- | --- |
| **サイズ** | 使うプリセット。 |
| **追加...** | プリセットを追加します。幅と高さは、選択中のプリセットの値から始まります。同じ名前のプリセットがあれば上書きします。 |
| **削除** | 選択中のプリセットを削除します(確認が出ます)。 |
| **カラーモード** | RGB、グレースケール、インデックス。 |
| **背景** | 透明、白、背景色(Aseprite のカラーバーで今設定している背景色)。 |

**作成** を押すと新規スプライトができます。

### プリセットファイル

プリセットは、Aseprite の設定フォルダ(スクリプトフォルダの1つ上)にある `canvas_presets.txt` に保存されます。

| OS | 場所 |
| --- | --- |
| Windows | `%APPDATA%\Aseprite\canvas_presets.txt` |
| macOS | `~/Library/Application Support/Aseprite/canvas_presets.txt` |
| Linux | `~/.config/aseprite/canvas_presets.txt` |

初めて実行したときに、次のプリセットが入った状態で作られます。

```
# 名前,幅,高さ (1行に1つ)
16px,16,16
32px,32,32
64px,64,64
```

1行に `名前,幅,高さ` を書きます。`#` で始まる行は無視されます。テキストエディタで書き換えると、次にスクリプトを実行したときから反映されます。

英語版も同じ `canvas_presets.txt` を使うので、両方入れた場合もプリセットは共通です。

## GIFをレイヤーとして読み込み

GIF アニメーションを、開いているスプライトに読み込みます。GIF の1フレームがスプライトの1フレームに対応します。

- 新規レイヤー(選択中のレイヤーのすぐ上に作り、名前は GIF のファイル名)に読み込むか、選択中のレイヤーの絵の上に重ねるかを選べる
- 今のフレームから、または1フレーム目から並べられる
- ピクセル等倍のほか、キャンバスに収める・埋める・引き伸ばすこともできる
- フレームが足りなければ後ろに追加し、長さは GIF のフレームに合わせる
- 読み込み全体を1回の **編集 > 元に戻す**(Ctrl+Z)で取り消せる

### 使い方

RGB モードのスプライトを開き(変換するときは **スプライト > カラーモード > RGBカラー**)、**ファイル > スクリプト > GIFをレイヤーとして読み込み** を実行します。

| 項目 | 説明 |
| --- | --- |
| **GIF ファイル** | 読み込む GIF。 |
| **読み込み先** | **新規レイヤー**、または **選択中のレイヤー(上に重ねる)**。後者は選択中のレイヤーの絵の上に GIF を重ねます。ロックされていない普通のレイヤーを選んでください(グループ・タイルマップ・参照レイヤーは不可)。 |
| **開始位置** | GIF の1フレーム目をどこに置くか。**今のフレームから** または **1フレーム目から**。 |
| **サイズ** | **ピクセル等倍**:そのままの大きさ。<br>**キャンバスに収める**:GIF 全体がキャンバスに収まるように拡大縮小(余白が出ることがある)。<br>**キャンバスを埋める**:キャンバス全体を覆うように拡大縮小(はみ出した部分はキャンバスの外に残る)。<br>**キャンバスに引き伸ばす**:縦横比を無視してキャンバスと同じ大きさにする。 |
| **拡大縮小の方法** | **ニアレストネイバー** はドットがくっきり残ります(ドット絵向け)。**バイリニア** はなめらかになります。拡大縮小するときだけ使います。 |
| **配置** | **中央** または **左上**。「キャンバスに引き伸ばす」のときは使いません。 |
| **フレームが足りなければ追加する** | GIF のフレームがスプライトの残りフレームより多いとき、後ろにフレームを追加します。オフにすると、入りきらない分は読み込みません。 |
| **既存フレームの長さも GIF に合わせる** | GIF を置いた既存フレームの長さ(表示時間)も GIF に合わせます。 |

**読み込み** を押します。

選択中のレイヤーにリンクセルがある場合は、GIF を重ねたフレームのセルだけリンクを外すので、ほかのフレームは変わりません。

### コマンドライン

UI なしで実行するときは、`--script-param` でオプションを渡します(`--script` より前に書きます)。

| パラメータ | 値 |
| --- | --- |
| `file` | GIF のパス(必須)。 |
| `dest` | `current` で選択中のレイヤーに重ねる。省略時は新規レイヤー。 |
| `size` | `fit`(収める)、`cover`(埋める)、`stretch`(引き伸ばす)。省略時はピクセル等倍。 |
| `method` | `bilinear`。省略時はニアレストネイバー。 |

## 全レイヤーの色を置き換え

スプライトの全レイヤー・全フレームにある指定した色を、まとめて別の色に置き換えます。

- グループの中のレイヤーや非表示のレイヤーも対象
- ロック中・タイルマップ・参照レイヤーは対象外
- 元のピクセルの透明度は残すので、半透明のピクセルは半透明のまま
- 置き換え全体を1回の **編集 > 元に戻す**(Ctrl+Z)で取り消せる

### 使い方

RGB モードのスプライトを開き(変換するときは **スプライト > カラーモード > RGBカラー**)、**ファイル > スクリプト > 全レイヤーの色を置き換え** を実行します。

| 項目 | 説明 |
| --- | --- |
| **置き換える色** | 置き換えたい色。最初は今の描画色になっています。 |
| **新しい色** | 置き換え後の色。最初は今の背景色になっています。半透明の色にすると、置き換えたピクセルもその分だけ薄くなります。 |
| **許容範囲** | **置き換える色** にどれだけ近ければ置き換えるか(0〜255。赤・緑・青それぞれで判定)。0 だと完全に同じ色だけを置き換えます。 |

**置き換え** を押します。終わると、置き換えたピクセル数(飛ばしたレイヤーがあればその数も)が表示されます。

UI なしで実行したときは、許容範囲 0 で描画色を背景色に置き換えます。

## 効果レイヤーを作成

選択中のレイヤーのすぐ上に「効果レイヤー」を作ります。選択中のレイヤーの絵と同じ形を1色で塗りつぶし、乗算などのレイヤーモードを設定したレイヤーです。元のレイヤーに直接描かずに、影・色味・光を足したいときに便利です。

- 選択中のレイヤーに絵があるすべてのフレームに作る
- 新しいレイヤーの名前はレイヤーモードと元のレイヤー名から付く(例: `乗算 (レイヤー 1)`)
- 作成全体を1回の **編集 > 元に戻す**(Ctrl+Z)で取り消せる

### 使い方

RGB モードのスプライトを開き(変換するときは **スプライト > カラーモード > RGBカラー**)、普通のレイヤー(グループ・タイルマップ以外)を選んでから、**ファイル > スクリプト > 効果レイヤーを作成** を実行します。

| 項目 | 説明 |
| --- | --- |
| **色** | 塗りつぶす色。最初は今の描画色になっています。 |
| **レイヤーモード** | 新しいレイヤーのレイヤーモード(初期値は乗算)。 |
| **不透明度** | 新しいレイヤーの不透明度(0〜255)。 |
| **元レイヤーの半透明を反映する** | オンにすると、元のレイヤーで半透明のピクセルは効果レイヤーでも半透明になります。オフにすると、元のレイヤーの透明度に関係なく色をそのまま塗ります。 |

**作成** を押します。

効果レイヤーは作った時点のコピーです。あとで元のレイヤーを描き直しても、効果レイヤーは追従しません。レイヤーモードと不透明度は、あとから **レイヤー > プロパティ** で変えられます。

UI なしで実行したときは、描画色・乗算・不透明度 255 で作ります。

## ベジェ曲線

「曲線レイヤー」を追加する拡張機能です。曲線レイヤーの線はベジェ曲線で引かれ、いつでも編集できます。レイヤーを選ぶだけで、キャンバス上で点を動かしたり、曲がり具合・色・太さを変えたりできます。

- お絵かきアプリのペンツールのように、キャンバス上でクリック・ドラッグして描く。設定は小さなパネルにまとまっている
- 1つのレイヤーに何本でも線を引ける。色と太さ(1〜32px、丸ブラシ)は線ごとに設定できる
- 1px の線をきれいにするピクセルパーフェクトと、縁をなめらかにするアンチエイリアス(RGB・グレースケール)に対応
- 始点と終点をつないで閉じた形も作れる。内側を色で塗りつぶすこともでき、線なしで塗りだけにもできる
- 線の変形:キャンバス上のボックスで拡大縮小・回転・シアー・反転・移動ができる。数値を入力しての変形もできる
- フレームごとに別の線を持てる
- RGB・グレースケール・インデックスのどのカラーモードでも使える

### 使い方

**レイヤー > 新規 > 新しい曲線レイヤー** を選びます(タイムラインのレイヤーの右クリックメニューにもあります)。選択中のレイヤーのすぐ上に `曲線 1` というレイヤーができます。曲線レイヤーはタイムラインで緑色に表示されるので、ほかのレイヤーと見分けられます(以前の版で作った曲線レイヤーは、次に編集したときに緑色になります。自分でレイヤーの色を付けている場合は、その色のままです)。

曲線レイヤーを選んでいる間は、その線をキャンバス上で直接編集でき、ウィンドウの右端に小さなパネルが開きます。ホイールでの拡大縮小や、Space+ドラッグでのスクロールは普段どおり使えます。

| キャンバスでの操作 | できること |
| --- | --- |
| 何もないところをクリック | 新しい図形を描き始めます。図形を描いている途中(または図形を選択中)なら、その図形の最後に点を追加します。 |
| 何もないところから押したままドラッグ | 点を追加してハンドルを伸ばし、線を曲げます。 |
| 描いている図形の最後の点をクリック、または **Enter** | その図形の描画を終えます。次に何もないところをクリックすると、新しい図形を描き始めます。 |
| 描いている図形の始点をクリック | 図形を閉じて(最後の点を最初の点につないで)、描画を終えます。図形は選択されたままになります。 |
| 点をドラッグ | 点を動かします。 |
| ハンドルをドラッグ | 線の曲がり具合を変えます。反対側のハンドルも一緒に回ります(**ハンドルを片側だけ動かす** がオフのとき)。 |
| 線をクリック | その図形を選択します。選択中の図形の線をクリックすると、形を変えずにそこへ点を追加します。 |
| 塗りのある図形の内側をクリック | その図形を選択します(塗りが重なっているところでは、上にある図形)。塗りの上から新しい図形を描き始めたいときは、先に **新しい図形** を押します。 |
| 線や塗りの内側をドラッグ | 図形全体を動かします。 |
| 点をクリック | 点を選択します(白い枠で囲まれます)。 |
| **Delete** / **Backspace** | 選択中の点を削除し、その前の点を選択します(続けて押すと点を順に削除します)。点を選ばずに図形を選択しているとき(線や塗りをクリックしたときや、図形を閉じたとき)は、図形ごと削除します。 |
| **Ctrl+Z** / **Ctrl+Y** | 元に戻す / やり直す。まず最近の線への変更を戻し、そのあとは Aseprite の履歴を戻します。 |
| **Esc** | ドラッグ中の操作を取り消すか、図形の描画を終えて選択を解除します。 |

図形を描いている間は、クリックはすべてその図形への点の追加に使われ、ほかの図形はつかめません。ほかの図形の点から描き始めたり、線をまたいで描いたりできます。塗りの内側でも、クリックやドラッグで点を追加できます(ドラッグすると曲線の点になります)。描画を終えたあとは、ほかの図形の線をクリックするとその図形を選んで編集できます。

「確定」の操作はありません。ほかのレイヤーやフレームを選んだり、保存やフィルターなどほかのコマンドを使ったりすると、変更が Aseprite の元に戻す履歴に1回分として入ります(**編集 > 元に戻す** / Ctrl+Z)。曲線レイヤーをもう一度選べば、続けて編集できます。ファイルを保存して開き直したあとも同じです。

編集中は、点とハンドルが曲線レイヤーに明るい緑色で表示されます。点は 3×3 ピクセルの四角(選択中の点は薄い緑、ほかの線の点は濃い緑)、ハンドルは点線で、先端が1ピクセルです。点の四角のどこをクリックしても、その点をつかめます。

グレースケールのスプライトや、パレットに緑がないインデックスのスプライトでは緑を表示できないため、ガイドは白黒になります。点は黒い縁取りに白い中心(選択中の点は逆)、ハンドルは白黒の点線で、ハンドルの先端は絵に対して目立つほう(黒か白)になります。インデックスのパレットに明るい緑を足すと、ガイドは緑になります。レイヤーを離れると消えます。拡大表示で使うと操作しやすくなります。

パネルの上部には、操作の説明と、その下に図形の追加・削除・コピー・貼り付けのボタンがあります。その下の大項目 **選択中の図形** には、選択中の図形の設定が並びます。その中は、図形のまわりの線の設定 **線** と、内側の設定 **塗り** の2つの小項目に分かれています。

| パネル | 説明 |
| --- | --- |
| **新しい図形** | 今の図形の描画を終えます。次のクリックで新しい図形を描き始めます。 |
| **図形を削除** | 選択中の図形を削除します。 |
| **コピー** / **貼り付け** | **コピー** は選択中の図形を、図形を選んでいないときはそのフレームのすべての図形をコピーします。**貼り付け** は、編集中のフレームの同じ位置に追加します。ほかのフレーム・レイヤー・スプライトにも貼り付けられるので、アニメーションに便利です。まったく同じ図形の上に重なるとき(コピーしたフレームに貼り付けたときなど)は、見えるように 4 ピクセルずらして(キャンバスの内側に向かって)置くので、図形の複製にも使えます。1個だけ貼り付けたときは、その図形が選択されます。フレームの図形を丸ごとコピーしたいときは、タイムラインでセルをコピーしても(Ctrl を押しながらセルをドラッグする、など)、曲線のデータが一緒にコピーされ、そのまま編集できます。 |
| **アンチエイリアス(縁をなめらかに)** | 線と塗りの縁を半透明のピクセルでなめらかにします。図形が重なるところは色が混ざります。RGB とグレースケールのみです。インデックスのスプライトでは半透明のピクセルを使えないため、オフになります。 |
| **線**: **線を描く** | オフにすると線を描かず、塗りだけになります。 |
| **線**: **色** | 線の色。最初は今の描画色になっています。 |
| **線**: **太さ** | 線の太さ(1〜32 ピクセル)。 |
| **線**: **ピクセルパーフェクト(太さ1のとき)** | 1px の線の角にできる、重なったピクセルを取り除きます(図形の点そのものは残すので、四角の角などはきれいに残ります)。アンチエイリアスのときは使いません。 |
| **塗り**: **内側を塗りつぶす** | 図形の内側を塗りつぶします。始点と終点をつないでいない図形は、両端を直線で結んだ形として塗ります。線は塗りの上に描かれます。 |
| **塗り**: **色** | 塗りつぶしの色。 |
| **ハンドルを片側だけ動かす** | ハンドルをドラッグしても反対側が回らなくなり、とがった角を作れます。 |
| **ガイドを表示** | 点とハンドルの表示を切り替えます。図形だけの見た目を確かめるときに使います。 |
| **始点と終点をつなぐ** | 選択中の図形の最後の点を、最初の点につなぎます。描いている途中の図形をつなぐと、その図形の描画も終わります(選択されたままになります)。 |
| **点を削除** | 選択中の点を削除します。 |
| **丸/角** | 選択中の点を、丸(ハンドルあり)と角で切り替えます。 |
| **変形ボックス**、**数値で変形...**、**反転**、**回転**、**縦横比を保つ** | 図形を変形します(下を参照)。 |
| **元に戻す** / **やり直す** | 図形への変更を元に戻す / やり直す。 |
| **閉じる** | パネルを閉じてこのレイヤーの編集をやめ、Aseprite のツール(移動ツールなど)を使えるようにします。パネルの × ボタンで閉じても同じです。レイヤーを選び直すか、**レイヤー > 曲線を編集** でまた編集できます。 |
| **ラスタライズ** | 曲線レイヤーを普通のレイヤーにします(下を参照)。 |

図形を選んでいるときは、項目にその図形の設定が表示され、変えるとその図形が変わります。図形を選んでいないときは、大項目の名前が **次に描く図形** になり、次に描く図形の設定になります(描いている途中は **図形を描画中** と表示されます)。

アニメーションの再生中も編集は止まり、Enter で再生を止めると再開します。

### 線の変形

変形は選択中の図形にかかります。図形を選んでいないときは、そのフレームのすべての図形にかかります(どちらになるかはパネルに表示されます)。1回の変形が1回分の「元に戻す」になります。点はピクセルの位置にそろい、ハンドルも線と一緒に回ったり伸びたりします。

- **変形ボックス**(または **編集 > 変形**、Ctrl+T)で線のまわりにボックスが出ます。モードが2つあり、ボックスの内側をクリックすると切り替わります。

  | モード | ハンドル | ドラッグすると |
  | --- | --- | --- |
  | 拡大縮小 | 角と辺の四角 | 拡大縮小します。反対側の辺は動きません。反対側を越えてドラッグすると反転します。**縦横比を保つ** をオンにすると、角のハンドルで縦横の比率が変わりません。 |
  | 回転・シアー | 角の丸 | 中心軸(小さな十字の印)のまわりに回転します。15°の倍数に近づくと、ぴったりの角度に吸い付きます。 |
  | | 辺のひし形 | シアー(傾け)します。ドラッグした辺が平行にずれ、中心軸を通る線は動きません。反対側の辺を固定したいときは、先に中心軸をその辺に動かします。 |
  | | 十字 | 回転とシアーの起点になる中心軸を動かします。たとえば点の上に動かすと、その点を軸に回転できます。図形の点、図形の範囲の角と辺の中央、元の中心に吸い付きます。位置は記憶され、ファイルにも保存されます。図形ごとに1つずつあり、さらにフレームごとに、図形を選ばずにすべての図形を変形するとき用のものが1つあります。図形を移動・変形すると一緒に動きます。元の中心までドラッグして戻す(吸い付きます)と、記憶は消えます。 |

  ボックスの内側をドラッグすると線を移動できます。Enter・Esc・ボックスの外側をクリック・**変形を終える** で終わります。
- **数値で変形...** では、横幅・高さ(%)、回転(°、時計回り)、横・縦の傾き(°)を入力できます。入力中も結果が表示されます。どれも図形の中心を基準にします(変形ボックスの中心軸を動かしているときは、そこを基準にします)。
- **左右反転** / **上下反転** と **左に90°回転** / **右に90°回転** はすぐに実行されます。曲線レイヤーの編集中は、Aseprite の **編集 > 左右反転** / **上下反転**(Shift+H / Shift+V)と **編集 > 回転** も同じように線を変形します(**スプライト > キャンバスの回転** や **キャンバスの左右反転** / **上下反転** は、これまで通りスプライト全体の絵にかかります)。

### ラスタライズ

**レイヤー > 曲線レイヤーをラスタライズ**(タイムラインの右クリックメニューや、パネルの **ラスタライズ** ボタンからも使えます)で、曲線レイヤーを普通のレイヤーにします。絵はそのまま残りますが、線を曲線として編集することはできなくなり、代わりに Aseprite のツールで描き込めるようになります。セルは絵のある範囲に切り詰められ、レイヤーの緑色も外れます。**編集 > 元に戻す**(Ctrl+Z)で曲線レイヤーに戻せます。

### 補足

- 線のデータはセルに保存されるので、`.aseprite` ファイルに残ります。PNG などほかの形式で保存すると、ピクセルしか残りません。
- 曲線レイヤーを移動ツールで動かしても、線のデータも一緒に動きます。
- 新しいフレームやコピーしたセルにも線のデータが引き継がれます。フレームをコピーして、次のポーズに合わせて線を直す、といった使い方ができます。リンクセルは同じ線を共有します。
- 曲線レイヤーのフレームがほかの方法で変更されている(手で描き足した、フィルターをかけた、など)ときは、その変更がうっかり消えないように、すぐには編集できません。**レイヤー > 曲線を編集** を使うと、確認のあとで線のデータから描き直します。
- 以前のスクリプト版ベジェ曲線で作った曲線レイヤーも、そのまま使えます。スクリプトフォルダの古い `ベジェ曲線.lua` は削除してください。
- 点とハンドルは曲線レイヤー自体に描かれるので、上のレイヤーに隠れたり、レイヤーの不透明度やレイヤーモードの影響を受けたりします。

### できないこと

Aseprite のスクリプトは、キャンバスの上に補助線を描いたり、キャンバス上で押されたマウスボタンや修飾キーを知ったりできません。そのため点とハンドルはピクセルで表示し、点の削除・角の作成・線の描画の終了は、右クリックや Alt の代わりにパネル・Delete キー・Enter・Esc で行います。ハンドルの位置はピクセル単位になります。

クリックのすぐあとに続けてクリックすると、ダブルクリックとして扱われて無視されることがあります。近くに点を続けて置くときは、少し間をあけてクリックしてください(編集中は、環境設定の **ダブルクリックでグリッドタイルを選択する** をオフにし、終わると元に戻します)。

[`extensions/bezier-curve`](extensions/bezier-curve) フォルダから拡張機能のファイルを作り直すときは、`python3 extensions/build.py` を実行します。

## 動作環境

Lua スクリプトに対応した Aseprite(v1.3 以降を推奨)。拡張機能のベジェ曲線は v1.3 以降が必要です。
